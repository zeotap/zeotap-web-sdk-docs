### 🐛 Bug Fixes
* **Consent & Identity Thread Safety**: Fixed a crash caused by concurrent access to consent and user identity state from multiple threads. All mutable consent and identity state is now synchronised internally, with no public API changes.
* **Page Properties Thread Safety**: Fixed a crash in event serialisation caused by page properties being updated while an event was being built. Page property updates are now processed on the SDK's event queue, so events always carry the page properties that were set at the time they were logged.
